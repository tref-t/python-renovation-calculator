# БудКалькулятор (МайстерОк на Django)

Сучасний веб-сайт професійних будівельних калькуляторів для виконробів, майстрів та ремонту своїми руками.

Розроблено на Python 3.11+ / Django 5 / HTMX / Tailwind CSS.

## Особливості проекту

### 10 ключових будівельних калькуляторів:
1. **Ламінат** (пачки, підкладка, плінтус, монтажні клини, спосіб укладання)
2. **Стяжка підлоги** (ЦПС М150, самозаміс 1:3 цемент+пісок, напівсуха стяжка з фіброю, демпферна стрічка, маяки)
3. **Керамічна плитка** (керамограніт, клей у мішках, затирка для швів за ГОСТ, кліпси СВП)
4. **Газобетонні блоки** (чиста площа стін, кубометри, піддони, клей, арматура Ø8 мм для штроб)
5. **Цегла будівельна** (одинарна, полуторна, подвійна, товщина кладки 0.5–2.5 цеглини, розчин)
6. **Штукатурка стін** (гіпсова Knauf Rotband, цементна, маяки 6 мм, ґрунтовка)
7. **Шпаклівка** (стартова, фінішна суха чи готова паста у відрах за шарами)
8. **Ґрунтовка глибокого проникнення** (акрилова, для пористих основ, Бетоноконтакт)
9. **Фарбування стін та стелі** (латексна, акрилова, силіконова, банки 0.9–14 л)
10. **Шпалери** (0.53 м і 1.06 м, рапорт малюнка, смуги, рулони, клей)

- **Миттєва інтерактивність (HTMX):** Результати, специфікація матеріалів і попередження оновлюються на льоту при зміні будь-якого поля без перезавантаження сторінки.
- **Друкована форма / PDF:** Вбудована стилізація для друку кошторису або збереження у форматі PDF прямо з браузера.
- **Повна українська локалізація:** Усі поля, підказки, поради майстра та одиниці вимірювання українською мовою.
- **Тестове покриття:** Повний набір тестів на pytest (перевірка математики формул, статусів відповідей, HTMX та JSON API).
